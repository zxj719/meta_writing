# 自动生成学习规则

写作过程中发现的需要避免的模式。

## 当前项目流程规则（2026-04-08）

> 这本书的正文流程先回退到前五章的人工主导模式，`auto_runner.py` 不再承担自动成稿和自动重写职责。

- 规则1：后续章节默认不用 `auto_runner.py` 直接生成正文，也不用它自动回写修订版。
- 规则2：正文生产顺序固定为“人工起草/人工续写 -> 人工审读 -> 局部手工修订 -> 确认后再更新项目状态”，不要再把自动多轮修订当成默认链路。
- 规则3：如果需要工具辅助，只能把 `auto_runner.py` 用在规划、连续性检查、风格检查等离线参考环节，且结果必须人工筛选后才能吸收。
- 规则4：第7章开始允许恢复更轻快、更耍宝的番茄节奏，但总体质感必须继续贴近第1章到第5章，而不是另起一种更严肃或更文学化的写法。

## 第6章回滚后保留的纠偏规则（2026-04-08）

> 本次错误 auto-run 暴露的是“跨项目审美污染”，不是这本书本身的方向问题。后续章节必须继续保持番茄都市重生系统文节奏。

- 规则1：本书固定风格是“番茄女频 + 都市重生 + 系统 + 偏执男主救赎”，禁止把章节改写成另一部小说的“克制美学/微感文学”风格。
- 规则2：世界观必须留在当前项目已铺垫的校园、系统、白莲花反扑和男女主拉扯线上，禁止引入“物体记录时间”“微感者”等外部设定污染正文。
- 规则3：角色和叙事核心必须固定为沈清辞、顾夜舟、苏晚宁与当前校园冲突，禁止改名、换 POV、偷换成长线主题。
## 第6章人工反馈沉淀规则（2026-04-08）

> 第6章的问题不是情感不够，而是表达密度失衡。后续修订和新章生成都要保留情感核心，同时把对话、系统、支线堆叠压回前五章的节奏。

- 规则1：沈清辞的台词要保持第3到第5章那种碎、生活化、带点嘴快和临场反应的质感，不要连续输出“我知道”“我能”“我只需要”这类金句式断言。
- 规则2：系统可以保持活泼、吐槽感和抓眼的存在感，不必刻意压成低频；但它只能做节奏点缀和信息提示，不要在关键情感对话里连续刷屏，更不要替主角承担情感表达。
- 规则3：同一章只推进一到两个核心点。情感拉扯场一旦成立，就不要再硬塞八卦插科、白莲花后续和新日期伏笔来切断情绪。
- 规则4：插入性配角信息必须服务转场或推进主冲突。像李佳佳这种八卦位，如果不能缓冲节奏或制造实质信息，就删掉或后移。
- 规则5：控制“是，不是”这类口癖和连续短断句，避免整段对话读起来像演员背台词。
- 规则6：重生与真相只能侧面暗示，前中期不要让沈清辞直接说破“因为我先回来了”这种会过早改变关系结构的台词。
- 规则7：保留第6章的情感浓度和细腻观察，但整体对话量压缩约30%，把真正有力的句子留到最该落锤的位置。

## 后续章节新增生成规则（2026-04-15）

> 这批规则不是换风格，而是补齐后半程容易发空的部分：配角层、恋爱层、视觉层。

- 规则1：后续可以引入“逃出来的幸存样本”型配角，但必须低调出场，功能是补线索、补侧证、映照顾夜舟，不要一登场就接管剧情。
- 规则2：配角不能只是工具人嘴替。即使戏份不多，也要给出一两个可记住的特征，例如旧伤、习惯动作、见到顾启明名字时的反常反应。
- 规则3：主线推进时要同步发展感情线，不能只剩查案、对峙和爆点。后续章节允许加入高三地下恋、偷偷外出、短暂约会、一起透气这类校园亲密片段。
- 规则4：轻松章节或短支线的作用是“让关系落到日常”，不是灌水。出去玩、一起买东西、绕路回家这类片段都要同时推进关系和人物认知。
- 规则5：男女主外貌必须固定成可反复调用的视觉锚点，不能一章写得很惊艳，后面又消失。顾夜舟是冷白、阴郁、骨相锋利那一挂；沈清辞是明艳、浓颜、带攻击性的那一挂。
- 规则6：外貌描写不要写成空泛吹颜值，要落到具体画面里：灯光、站姿、视线停顿、校服和礼服的反差、别人被晃到一下的反应。
- 规则7：成人礼是后续重要场景资源，不能一笔带过。它既能给男女主发光，也能制造地下恋拉扯，还能给反派线提供切入口。
- 规则8：沈清辞前世那个让她犯恋爱脑的对象，后续必须出场，不要只存在于人物简介里。
- 规则9：这个旧对象出场时，功能不是单纯恶心人，而是要同时完成“打脸过去错误选择”“衬出顾夜舟这条线的分量”“让沈清辞真正与前世切割”三件事里的至少两件。
- 规则10：陆闻川当前阶段只按“螳螂”处理。他负责校园内的执行、筛查和借成人礼搞事，但不要在高中阶段把他写成最终黄雀；更高层的操盘方和真正大组织留到大学线再掀。
- 规则11：陈渡只是第一个漏网幸存样本，后续还要慢慢引出更多边缘异能者和不起眼配角，但不能一次性发卡式上人。每次出场最多抬一个新入口，先给特征，再给身份。
- 规则12：异能者扩展不能写成设定说明书。要通过校园生活里的小异常、旧伤、体检回避、拍照失真、广播不适、志愿者名单异常等具体现象把世界观慢慢撑开。
- 规则13：正面组织“异控局”可以铺，但前期只能以痕迹、术语、旧记录、被保护过的人和干净善后方式出现，不要提前整队登场，不要抢走校园阶段的主叙事。
- 规则14：成人礼必须让男女主都参加，而且礼服就是外貌高光时刻，要写到足够惊艳。不要只写“好看”，要写肩线、腰线、站姿、妆发、灯光和别人看呆一瞬的反应。
- 规则15：成人礼章节允许适当松节奏，穿插普通高三生活，例如校服签名、互写寄语、班级合影、散场夜路、后台整理衣领和头发。这些片段不是灌水，是给高压主线留呼吸位。
- 规则16：男女主第一张正式合照要作为一个明确的情感节点来写，最好落在成人礼相关场景里。照片本身既是纪念物，也能成为后续回收的情感锚点。
- 规则17：校领导演讲不能只做背景音。如果成人礼现场有领导发言，这段要么承担校园真实感，要么承担轻冲突、小钩子、观察视角或反派布线，不要写成可删的空段。
- 规则18：乔知夏和陈渡当前阶段要继续低存在感，不能突然高频露脸、主动讲设定、主动认领身份。他们的功能是让读者先感觉“有第三方在看”，不是马上告诉读者“第三方是谁”。
- 规则19：作者内核方向上，乔知夏和陈渡从“像漏网样本的人”调整为“更像异控局埋在校园阶段的潜伏调查者”。但这层真相在正文里必须藏住，当前阶段正反派都不该明确知道他们的目的。
- 规则20：这两人的露面方式以岗位和流程为主，例如摄影、广播、后勤、器材、校门外观察、临时巡查名单，不要写成突然开会、突然摊牌、突然并肩作战。
- 规则21：异控局的正式存在感要继续压后。高中阶段只允许出现调查者痕迹、干净术语、保护动作和第三方监测，不允许组织整队登场抢主线。
- 规则22：顾夜舟妈妈后续要埋成异控局核心人员方向，但现阶段只能通过旧照片、未解释完的求助记录、留下的资料、被保护过的痕迹来慢慢立住，不要太早把她从“顾夜舟旧伤来源”直接写成“核心大人物”。

## 第36章后新增纠偏规则（2026-04-20）

> 这一轮主要解决两个问题：一是句式继续去AI腔，二是把后续大设定从“个人重生”升级成“回溯机制”。

- 规则23：后续正文禁止频繁使用“那……很……，但……”和“那……不……，但……”句式。这类句子不要用来写神态、情绪、声音和氛围，容易显得像固定模板。
- 规则24：每章开头避免使用“……一……，就……”起手式。开篇要尽量换成具体画面、动作、环境声或有钩子的对白。
- 规则25：不要用“那一声很轻，但他听懂了”这种作者替读者解释的句子。改成对方停顿、手指变化、视线移动、话被吞回去等可见反应。
- 规则26：顾夜舟妈妈不是单纯死于车祸的受害者。外界可以继续认为她“车祸尸骨无存”，但真实方向是她当年可能被某些人救走，并且陆闻川没有察觉或没有掌握完整真相。
- 规则27：顾母线要慢慢埋，不要突然让她现身。当前阶段只允许通过旧工作牌、B-17、保护痕迹、被清空的档案、蓝色圆戳、旧照片缺口来加深。
- 规则28：沈清辞的“重生”不是唯一异常，后续要逐步升级为“回溯/重开故事线”机制。她以为自己只是重生，但真相可以是有人或某种能力把她送回了关键节点。
- 规则29：重来的不止沈清辞一个。其他人可以有残留既视感、异常反应、提前规避、对前世事件的模糊偏离，但不要一次性揭晓。
- 规则30：沈清辞必须有“为什么是她被送回”的硬原因。这个原因要和07号、识伪共振、系统、顾母保护线或第三方回溯机制绑定，不能写成随机天降。
- 规则31：沈清辞上辈子不能写成单纯愚蠢或无脑恋爱脑。她的错误选择应来自信息差、情感利用、证据被摆错方向、身边人系统性误导，以及她当时有限视角下看似合理的判断。许知衡线要写成“被精心包装过的错误路径”，不是“女主眼瞎”。
- 规则32：后续可以插入上辈子后期顾夜舟的片段，用来对照这辈子的少年顾夜舟，合理化男女主上一世羁绊。上辈子后期的顾夜舟应保持阴郁、危险、压迫感强、少话但行动保护的形态；他不是温柔解释型，而是用文件、证据、挡灾、沉默守护来证明自己从未把刀尖对准沈清辞。
- 规则33：新人物或关键旧人重新登场时，不要先写“这个名字不好笑”“他不是那种坏人”这类作者判断句。应先给可见细节和具体记忆：外貌锚点、动作习惯、曾经做过的事、旁人的反应，再让读者自己得出“可靠/危险/会诱导人”的判断。
- 规则34：系统保密时，不要写“男主看不见系统”“他不知道系统存在”这种解释性句子。正文只写顾夜舟能看见的部分：沈清辞的停顿、手指收紧、眼神变化、突然改口，以及他由此产生的察觉。
- 规则35：许知衡正式出场已完成外貌高光。后续他仍是帅且亮的那一挂，但不要继续高频重复同一个眼型标签；他的“魅惑/信任诱导”能力初期不要明说成技能名，而是通过旁人自然放松警惕、说话被带偏、觉得他可靠来展示。
- 规则36：沈清辞的读心术后续要重新利用，但初期保持不稳定、次数有限、容易头疼或误读。重大节点可以让读心术突破，尤其适合用来对抗许知衡的魅惑/信任诱导；突破必须有代价，不要变成万能外挂。

## 第40章后新增羁绊与记忆覆写规则（2026-04-22）

> 这一轮主要解决“上辈子顾夜舟为什么帮沈清辞”的情感源头问题，并把许知衡线从普通前任错选升级为记忆被摆错方向的结构性误导。

- 规则37：顾夜舟上一世帮沈清辞不能写成无缘无故的“做慈善”。他的保护源头要落在具体场景里：沈清辞曾在他被围观羞辱时把他当人看，给过草莓牛奶、创可贴或同等级的生活化善意，所以他后来递证据、挡风险、沉默护她都有情感根。
- 规则38：许知衡让沈清辞相信自己的关键契机，可以来自“偷走顾夜舟的位置”。例如南门器材室雨夜里真正开门的人是顾夜舟，但沈清辞记忆里的开门者被覆写成许知衡。
- 规则39：记忆篡改不要靠角色大段解释。要用错位细节来证明：手不对、伞不对、伤口不对、声音不对、物件归属不对，让读者先发现“不合拍”，再让系统或角色给最少量确认。
- 规则40：双向记忆回流可以作为男女主羁绊升级手段，但必须服务情感和剧情两件事。沈清辞恢复的是被误导的信任证据，顾夜舟恢复的是自己为什么会爱她、护她的源头。
- 规则41：沈清辞以为自己重开一把是回来救顾夜舟，但后续大反转可以写成“顾夜舟回来找她”：上一世沈清辞死后，顾夜舟查到更深真相，提前布线并以死亡触发回线。这个真相要慢慢埋，不要在高中阶段直接明牌。
- 规则42：沈清辞前世“恋爱脑”必须彻底去污名化。她不是蠢，而是被许知衡的信任诱导/魅惑类能力、父辈合作关系、身边人证词、被摆错方向的证据和记忆覆写共同影响。
- 规则43：许知衡与沈清辞当前线重生前也应有合理交集。推荐设定为沈父合作伙伴之子，既符合沈清辞白富美人设，也解释开场前两人认识、但尚未发展到上一世错误亲密的状态。
- 规则44：顾夜舟必须有一门明面上足够出彩的学科来支撑许知衡“久仰”。定为化学竞赛方向：他数学可以不好，但化学要很强，能参加竞赛、拿奖，后续还能在实验、试剂、旧案残留上破局。
- 规则45：顾夜舟当前仍是高中阶段的阴郁少年，不是上一世后期的阴郁大佬。面对许知衡可以暂避锋芒，不要强行碾压；但嘴仗、冷淡拆台、用专业能力反杀“小茶狐狸”可以写。
- 规则46：李佳佳后续要从“人形弹幕机”升级为潜伏在校园日常里的信息节点。她可以早早发现顾夜舟做好事不留名，并用八卦传播让同学对顾夜舟改观，但她本人前期不必意识到这件事的重要性。
- 规则47：成人礼时同学敢找顾夜舟签名、拍照、开玩笑，后续可以用回溯补因：李佳佳在成人礼前已经悄悄传播过他的好事。毕业聚会或同学聚会时再由同学说漏嘴，让顾夜舟知道自己被大家重新看见。

## 第41章后新增回线与描写规则（2026-04-22）

> 这一轮主要解决两个后续方向：一是把“重生”升级成更有代价的平行时空/回线机制，二是让人物外貌描写摆脱重复词。

- 规则48：后续不要把沈清辞的经历简单写成“单人重生”。更准确的方向是平行时空/回线：他们回到了另一个可以改变未来的关键节点，每一次选择都可能让某一条线里的两个人再次失去彼此。
- 规则49：沈清辞回溯的代价很重。她失去的不只是零散记忆，而是大量上一世经历、关键情绪、救命细节和判断依据；这些记忆还可能被许知衡或更高层力量二次篡改，所以她现在的记忆应当呈现“缺口、错位、混线、残留细节互相打架”的状态。
- 规则50：许知衡可以带着上一世记忆来，或者来自另一个平行分支。正文当前阶段不要直接明牌，只通过他精准踩中旧记忆关键词、过度了解顾夜舟和沈清辞、对当前线偏离过分敏感来表现。
- 规则51：顾夜舟对沈清辞“重生/回线”的猜测要逐步推进。他不能突然全知道，而应从她的停顿、改口、对未发生事件的预判、旧记忆闪回后的失态、系统提示前后的反应里慢慢拼出结论。
